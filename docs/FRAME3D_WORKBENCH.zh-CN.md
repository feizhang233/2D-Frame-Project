# 3D 工作台

左上角 **2D / 3D** 切换两个独立模型。切换保留各自状态，不进行几何转换。
3D 调用现有主服务的 `POST /api/v1/3d/solve`，与二维使用相同的请求、超时和错误处理基础设施。

## 绘图流程

1. 选择工作平面 **XY / XZ / YZ**，再输入垂直方向的位置：XY 的 Z、XZ 的 Y、YZ 的 X。左右箭头跳到模型已有的相邻平面，没有下一层时按网格间距移动。
2. **Split view** 同时显示工作平面与空间总览。也可单独显示 **2D plane** 或 **3D view**。三维视图采用可旋转的正交投影。
3. **N / Node** 放置节点。**E / Element** 连续画杆：先点起点，再点终点；继续点击可连续连接，右键结束当前链，Esc 返回选择。
4. 打开坐标面板，直接输入节点 XYZ 或杆件起终点 XYZ。输入以米为单位，不受网格吸附舍入影响。三维视图中的点击也落在当前工作平面上；工作平面侧向投影为一条线时，提示转动视角或使用平面视图。
5. 画线经过既有节点或真正的空间交点时，自动分段并建立共享节点。空间错层杆件在屏幕上的交叉不建立连接。重复节点复用；重复杆件和零长度杆件拒绝创建。

拖动三维空白处旋转；Shift 拖动平移；平面视图拖动平移。滚轮或按钮缩放，Fit 恢复包围模型的视图。旋转与倾斜有独立按钮。画布获得键盘焦点后，方向键平移，`+ / -` 缩放，`F` 适配视图。

流程参考 CSI 官方的 [Set 2-D View](https://docs.csiamerica.com/help-files/sap/Menus/View/Set_2-D_View.htm)、[Draw Mode](https://docs.csiamerica.com/help-files/sap/Menus/Draw/Draw_Mode.htm) 和 [SAP2000 Tutorial](https://docs.csiamerica.com/manuals/sap2000/SapTutor.pdf)。本工作台实现上述建模习惯，没有声称与 SAP2000 的全部命令或文件格式兼容。

## 选择与赋值

单击对象选择，Shift 单击多选；**H / Tables** 的节点和杆件表也提供复选框选择。表格和两张画布共享选集。

| 面板 | 参数与行为 |
|---|---|
| M / Material | 独立材料模块：E、G（GPa），仅更新材料参数 |
| C / Section | 独立截面模块：A、Asy、Asz（cm²），Iy、Iz、J（cm⁴），仅更新截面参数 |
| Element formulation & orientation | 截面面板内独立展开项：梁理论、参考向量、转角（度）、六个局部转动端释放，单独应用 |
| Beam theory | Euler–Bernoulli 或 Timoshenko；后者仅允许节点荷载 |
| S / Supports | 六自由度约束、固定/铰支/Z向滚动预设、非零约束位移（m / rad）、可选倾斜支座的正交右手轴矩阵 |
| L / Loads | 全局节点力与力矩（kN / kN·m）；局部或全局的线性分布力（kN/m）及局部 x 向分布扭矩（kN·m/m） |
| H / Analysis & stress recovery | 每杆 2–2001 个结果站点；可选局部截面 y,z 坐标（m），逐行输入以恢复正应力 |

Material 和 Section 分别提供 **Apply to elements** 区域：点击 E 编号应用到单根构件，**Apply to selected** 应用到选集，**Apply all** 应用到全部构件。两类赋值互不覆盖，并保留构件方向、梁理论和端释放。**Use for new elements** 只设置后续绘图的相应默认参数，不修改已有构件。

2D 与 3D 共用浅绿色主题、工具栏和属性卡片样式。双击 **Select** 收起或展开左侧属性栏，选择其他建模工具自动展开；收起后的 Properties 按钮也可打开面板。

初始默认值为 E=210 GPa、G≈80.769 GPa、A=100 cm²、Iy=Iz=8330 cm⁴、J=14000 cm⁴，可在绘图前修改。

荷载 Apply 替换所选对象已有的同类荷载记录；其他对象保留。支座和荷载均支持移除。分段会线性插值原分布荷载，并仅在原构件两端保留端部释放。修改节点坐标会移动相连杆件；若参考向量因修改而平行于杆轴，需要在截面面板修改或自动对齐。

删除节点时同时删除关联杆件及荷载，并同步重排后端要求的连续节点编号。删除、新建、导入均可在当前会话中撤销；最多保留 50 次编辑。快捷键为 Ctrl/⌘ Z 和 Ctrl/⌘ Shift Z。

## 分析与结果

Run analysis 提交 SI 单位数据。界面中的单位换算只发生在输入输出边界。工作区名称不会进入严格的求解请求。

- 变形叠加图的 Scale 是显示倍数，不改变数学模型。
- 内力图包括 N、Vy、Vz、T、My、Mz，并显示最大绝对值与单位。相对同量纲结果极小的数值噪声不放大成图形。
- 表格包括节点位移、反力、局部杆端力、沿杆截面内力/正应力和数值校验，每页 20 行。
- 杆端力与正 local-x 面截面内力采用各自后端符号约定，表格下方有说明。
- 改动模型会取消未完成的分析并清除旧结果。失稳或输入问题显示在结果区，可修改后重试。正在分析时提供取消操作。

数学范围与限制遵循 [FRAME3D_MATH_CORE.md](FRAME3D_MATH_CORE.md)：线弹性、小位移、直杆、常截面空间梁；本界面不增加非线性、屈曲、动力学或实体截面显示能力。

## 文件与保存

3D 编辑后自动保存到当前浏览器的 `frame-studio.3d.model.v1` 草稿，失败会持续提示导出。这是本地草稿，不是云端模型库。**Export 3D JSON** 或 Ctrl/⌘ S 输出可直接发送到后端的严格请求结构，文件名保存工作区名称。**Open 3D JSON** 接受同格式及仓库示例，最大 10 MB；先校验，再确认替换。当前求解的显示设置与相机不写入 JSON。

桌面默认双视图；窄屏将属性改为抽屉，手机宽度默认单平面并保留三维切换。

浅绿色界面验收：2D / 3D 双击 Select 均能收起属性栏；桌面 3D 属性栏从 380px 收至 56px，其他工具可重新展开。材料、截面分别验证了单根、选集、全部赋值及绘图默认值的隔离，无效负数会保留并提示。390×844 下验证了 3D 抽屉和 2D 属性区内部滚动；撤销测试赋值后，示例模型再次求解通过校验，最大位移为 0.901686 mm。前端 12 项测试、生产构建及界面静态审查通过。

## 验证

前端行为测试（需要支持 TypeScript stripping 的 Node.js 22.6+ 和已安装依赖的 `.venv`）：

```sh
npm --prefix frontend test
npm --prefix frontend run build
MPLCONFIGDIR=/tmp/frame3d-mpl-cache .venv/bin/python -m pytest
```

测试覆盖三种平面的坐标逆映射、真实交点与错层交叉、重复/重叠杆件、荷载和释放分段、删除引用重排、输入校验、材料/截面独立赋值、单根/选集/全部赋值边界、示例导入，以及前端生成的分段模型通过严格后端接口求解。

浏览器验收包括：平面点击连续画杆、坐标绘杆、交点同步、2D/3D 状态保留、多选属性赋值、节点荷载、支座赋值、无效输入、失稳错误和撤销恢复。独立从空白建立的 3 m 悬臂梁，以 E=210 GPa、Iy=8.33×10⁻⁵ m⁴ 承受端部 Fz=−10 kN，页面显示端部 W=−5.14492 mm，与 −PL³/(3EIy) 一致。桌面与 390×844 视口均进行了实际浏览器检查。
